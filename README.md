# Puncture Help — GitHub Pages Prototype

A mobile-friendly prototype for a roadside tyre/puncture service marketplace.

## Included
- Customer mode
- Mechanic registration
- Mechanic online/offline status
- Nearby mechanic demo list
- Customer service requests
- Mechanic request acceptance
- Browser localStorage for prototype data
- Optional browser GPS permission

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Go to Settings → Pages.
4. Select Deploy from branch → main → / (root).
5. Open the generated GitHub Pages URL.

## Important
This version is a prototype. Data is stored only in the browser/device. It is not shared between different users/devices.

For the real version, connect the same frontend to Firebase or Supabase for authentication, shared mechanic registration, requests, real-time status/location, and notifications.
